## 一、项目概览

**Prompt Genesis** 是一个 AI-Native 2D 像素风沙盒生存微游戏。玩家以自然语言下达"神谕"，LLM 解析后驱动 3 个 NPC 执行行动，在 60 秒洪水倒计时内收集资源存活。

### 技术栈

| 层级 | 技术 |
|------|------|
| 游戏引擎 | Phaser 3.90 + TypeScript 6.0 |
| 构建工具 | Vite 8 + Tailwind CSS v4 |
| 服务端 | Express 5 + DeepSeek API（DeepSeek Chat, JSON Mode）|
| 音效 | Web Audio API（零外部资产）|
| 测试 | Vitest 4（70 用例）|
| 资产 | **零外部图片/音频** — 全部代码生成 |

## 二、已实现功能清单（28 大模块）

### 1. 核心游戏循环

- **60 秒倒计时**，`setInterval` 每秒驱动（挑战模式可覆盖为 30s）
- **三种资源**：木材、知识、饱食度（0-100%），支持兑换
- **三种结局**：胜利 ✅ | 饿死 💀 | 洪水淹没 🌊
- **饱食度衰减**：每 5 秒 -2%（受难度等级和挑战模式影响，最高 -5/5s）
- **完整状态机**：`createInitialGameState` → `tickSecond` → `applyStateImpact` → `evaluateSettlement`
- **挑战模式**：支持 `ChallengeConfig` 动态覆盖胜利条件

### 2. 三名 NPC 角色

| NPC | 类型 | 擅长 | 不擅长 |
|-----|------|------|--------|
| 阿强 👊 | 力量型 | 砍树效率 ×2 | 读书效率 ×0.5 |
| 阿珍 🧠 | 学者型 | 读书效率 ×2 | 砍树效率 ×0.5 |
| 阿衰 😌 | 恢复型 | 睡觉饱食恢复 ×2 | 干活消耗 ×1.5 |

- 独立像素精灵（16×16 网格 ×2 缩放 = 40×40 纹理），阿衰常驻呼吸动画
- **名称可自定义**（开始界面输入，localStorage 持久化，注入 SYSTEM_PROMPT）

### 3. NPC 行动系统

四种动作类型，通过 Promise 链编排：

| 动作 | 实现 |
|------|------|
| `WALK_TO` | Phaser 物理寻路 + 距离检测 + 10 秒超时保护 |
| `PLAY_ANIMATION` | CHOP（4 次挥砍旋转）/ READ（书本 + 翻页音效）/ SLEEP（躺平 + 鼾声）|
| `SPEAK` | 国风气泡 + 上浮淡出动画 |
| `IDLE` | 停止速度 + 隐藏道具 |

- **并行执行**：不同 NPC 的 WALK_TO 用 `Promise.all` 并行
- **心情 Emoji**：根据角色 + 行动匹配 💪😩🧠😌😅，1.6 秒淡出
- **NPC 主动行为**：NPC 在空闲时自发行动（见模块 12）

### 4. LLM 集成（DeepSeek）

- `POST /api/divine-command` — 接收神谕，调用 DeepSeek Chat（JSON Mode, temperature 0.3）
- `SYSTEM_PROMPT` ~90 行：定义角色、坐标、品质评分、连锁事件、资源兑换、地图变化规则
- 请求体附带 `npcState`（NPC 行动计数 + 抵触值 + 自定义名称）和 `history`（最近 3 条神谕）
- 45 秒超时 + 最多 2 次重试 + 退避策略

### 5. 叙事引擎 — WorldEvent 系统

8 种环境事件，独立镜头反馈 + 资源影响：

| 事件 | 镜头效果 |
|------|---------|
| STORM ⛈️ | 红色闪烁 + 震动 |
| FLOOD_SURGE 🌊 | 强烈震动 |
| RAIN 🌧️ | 轻微震动 |
| MOONLIGHT 🌙 | 蓝色柔光闪烁 |
| SUPPLY_CACHE 📦 / FIND_SUPPLIES 🎒 | 黄色闪烁 |
| WILD_BOAR 🐗 / DROUGHT 🏜️ | 红色闪烁 + 震动 |

- HUD 通知条淡入，5 秒自动消失，LLM 可在响应中附带

### 6. 神谕连锁系统 — AfterShock

- LLM 可生成与原神谕语义相关的"余震"事件，5 秒后自动触发
- 服务端 + 客户端 `sanitizeAfterShock` 双重校验
- 离线降级：高品质神谕 50% 概率生成连锁

### 7. 神谕品质评分

| 评级 | 图标 | 倍数 | 触发 |
|------|------|------|------|
| 📜 普通 | — | ×1.0 | 简单指令 |
| ✨ 优秀 | 绿色 | ×1.2 | 清晰合理、有创意 |
| 🌟 神谕 | 金色脉冲 | ×1.5 | 有画面感、贴合世界观 |

- 离线 `assessQuality` 通过关键词密度打分（场景词/叙事词/情感词）

### 8. 叙事结局系统

- `POST /api/generate-epilogue` — LLM 生成古风结局旁白
- 结算弹窗：叙事文本 → 分隔线 → 神谕编年史 → 新成就
- 离线通过 `generateMockEpilogue` 生成静态模板

### 9. 成就系统（8 项，localStorage 持久化）

| 成就 | 条件 | 策略 |
|------|------|------|
| 🎯 初露锋芒 | 第一次胜利 | 新手引导 |
| 🔮 读心者 | 满足全部 3 个 NPC 隐性目标 | 观察力 |
| 👊 暴君 | 只用阿强通关 | 单一角色 |
| 🧠 完人 | 三人各至少行动一次 | 均衡分配 |
| 🎲 赌徒 | 1 条神谕通关 | 极致规划 |
| ⚡ 绝境求生 | 最后 10 秒下达唯一神谕并通关 | 极限操作 |
| 💀 命悬一线 | 饱食度 <10 时通关 | 刀尖跳舞 |
| 📜 诗圣 | 获得"神谕"品质评价 | 高质量输入 |

### 10. 自适应难度（5 级）

| 等级 | 初始饱食度 | 衰减速率 | 需求木材 | 需求知识 |
|------|-----------|---------|
| 0 | 100 | -2/5s | 3 | 3 |
| 1 | 90 | -2.5/5s | 3 | 3 |
| 2 | 80 | -3/5s | 4 | 4 |
| 3 | 70 | -3.5/5s | 4 | 5 |
| 4 | 60 | -4/5s | 5 | 5 |
| 5 | 60 | -5/5s | 6 | 6 |

- **胜利** → 等级 +1（最大 5），**失败** → 等级 -1（最低 0），双向调节防卡死
- `createDifficultyConfig(level)` 生成参数，`tickSecond` 接受 `drainRate`
- HUD 木材/知识显示动态目标值（如 `2/4`）

### 11. NPC 人格漂移系统

- `localStorage` 持久化阿衰抵触值（0-100），每局被分配任务 +15，休息 -10
- 高抵触值：行走速度降至 60%、气泡变激烈
- SYSTEM_PROMPT 动态注入状态，LLM 据此调整任务分配
- 离线 Mock 同步调整语气
- **情绪传染**：阿衰抵触值 > 70 且靠近阿强（距离 < 90px）时，阿强伐木产出 -30%
- **阿珍心理疏导**：阿珍和阿衰同场且神谕品质 ≥ 优秀时，阿衰抵触值 -15

### 12. NPC 主动行为

NPC 在空闲时自发行动，世界永不静止：

| NPC | 自发行为 | 间隔 | 效果 |
|-----|---------|------|------|
| 阿强 | 走向古松林砍树 | 8-15s | 木材+1，饱食-2 |
| 阿珍 | 走向书斋翻书 | 10-18s | 知识+1，饱食-1 |
| 阿衰 | 走向竹榻躺下 | 5-10s | 饱食+3 |

- 气泡提示意图（"闲不住，砍点柴…"）
- 玩家指令**重置所有 NPC 定时器**，确保玩家控制优先
- 资源通过 `registry.proactiveImpact` 同步到 HUD

### 13. NPC 隐性目标系统

- 每局随机生成 NPC 心愿（阿衰 30% 想睡 / 阿强 20% 砍树 / 阿珍 20% 读书）
- **头顶黄色圆点**提示有心事，满足后变绿淡出
- 支持 `mind_reader` 成就

### 14. 资源兑换系统

- LLMResponse 新增 `trade` 字段，LLM 可根据神谕内容生成资源转换
- 服务端 + 客户端 `sanitizeTrade` 验证
- 状态栏显示兑换记录

### 15. 动态地图变化

- LLMResponse 新增 `mapMutation` 字段
- 5 种类型：`GROW_TREE / CHOP_TREE / BUILD / BURN / REPAIR`
- LLM 可根据神谕内容在地图上生成新元素（篝火、木堆、树木）
- GameScene 独立 `mutationGfx` 层绘制，去重防重复
- `proceduralArt.ts` 新增 `drawCampfire()` / `drawWoodpile()` 函数

### 16. 多轮对话记忆

- 每次神谕请求附带最近 3 条历史
- 服务端注入到 prompt 头部，LLM 可引用上轮内容
- 离线 Mock：连续让阿衰干重活 → 下一轮气泡变疲惫

### 17. 程序化像素艺术（零外部资产）

- 宣纸草地（确定性哈希噪点）、青花水域（正弦波闪烁）
- 古松（4 层三角叠加）、岭南书斋（镬耳墙）、竹榻（棕榈矩阵）
- 篝火（火焰三角）、木堆（堆叠矩形）— 动态地图变化用

### 18. 洪水粒子系统（4 阶段状态机）

| 阶段 | 条件 | 频率 | 速度 | 重力 |
|------|------|------|------|------|
| 0 | >50s | 1000ms | 30-70 | 80 |
| 1 | 30-50s | 300ms | 60-140 | 120 |
| 2 | 10-30s | 100ms | 120-220 | 220 |
| 3 | <10s | 30ms×3 | 200-450 | 450 + 爆炸 |

- `createCanvas` 粒子纹理 + `setDepth(2000)` 置顶

### 19. 音效系统（Web Audio API）

10 类音效，零外部资产：

| 音效 | 实现 |
|------|------|
| 环境嗡鸣 | 双振荡器 (72Hz+108Hz) + 噪声风层 |
| 神谕锣声 | 双正弦波 + 混响卷积 |
| NPC 砍树/翻书/鼾声 | 带通噪声 / 振荡器循环 |
| 危机心跳 | 55Hz 正弦波，40→120 BPM |
| 倒计时滴答 | 3kHz 噪声脉冲 |
| 胜利/失败 | 上行琶音 C5→C6 / 350→40Hz 下滑 |
| UI 悬浮/点击 | 600-1200Hz 正弦短脉冲 |

### 20. LLM 推理过程可视化

- 半透明浮层分 4 步 350ms 间隔展示：解析原文 → 识别目标 → 计算影响 → 神谕降下
- 从 `LLMResponse` 反向推导人类可读解析路径

### 21. 挑战模式（3 种）

| 挑战 | 规则 |
|------|------|
| 禁言风暴 | 限 2 条神谕通关 |
| 知识至上 | 知识 ≥5，木材不计 |
| 30 秒地狱 | 倒计时 30s，衰减翻倍 |

- 开始界面选择器，结算时 `challengeWins` 独立追踪
- `evaluateSettlement` 动态适配胜利条件

### 22. 自由模式

- 开始界面新增「自由模式」按钮，点击进入无倒计时、无资源压力的纯对话模式
- 时钟持续运行（NPC 主动行为 + AI Game Master 空闲叙事不受影响），但不调用 `tickSecond`
- 计时器显示绿色 `∞`，神谕品质评分/地图变化/主动行为全部正常运作
- 点击「再来一局」恢复正常模式

### 23. 语音输入

- 降下神谕按钮旁新增麦克风按钮 🎤
- 基于 Web Speech API（`SpeechRecognition`/`webkitSpeechRecognition`，中文 `zh-CN`）
- 识别完成后自动填入输入框并**自动降下神谕**
- 录音中按钮显示红色脉冲动画，浏览器不支持时灰显

### 24. 神之领域 — Bullet Time

- 输入框 **focus** 或语音按钮激活时，世界进入"墨域定格"状态
- 倒计时暂停（不调用 `tickSecond`），NPC 物理冻结（`physics.world.pause()`）
- 洪水粒子悬停（`floodEmitter.pause()`），相机覆盖半透明蓝幕
- 提交神谕/失焦输入框/语音结束后自动恢复
- 计时器显示蓝色 `⏸` 前缀，提示当前为定格状态
- 产品价值：LLM 网络延迟不消耗倒计时，字斟句酌的时间被包装为"神力凝聚"

### 25. HUD / UI（玄夜玉青流沙主题）

- Bento Grid 布局：木材/知识/计时器/饱食度/日志/画布/输入卡片
- 饱食度三段色进度条 + 危险脉冲；倒计时最后 10s 朱砂红
- 品质徽章（神谕级金色辉光）、世界事件通知条、推理浮层
- 输入框 placeholder 2.5 秒轮播 + NPC 名称编辑 + 挑战选择器 + 自由模式按钮
- 语音输入 🎤 按钮（Web Speech API 中文识别）
- **结局壁纸**：结算弹窗顶部 400×160 Canvas 像素插画（胜利/饿死/洪水三种风格）
- 对话气泡跟随 NPC 移动，地图变化反馈显示在状态栏
- 响应式：640px 以下切换 2 列网格

### 26. 反幻觉防护（双重防线）

```
服务端：stripMarkdownJson → sanitizeCommands/sanitizeStateImpact/sanitizeWorldEvent/sanitizeQuality/sanitizeAfterShock/sanitizeTrade/sanitizeMapMutation
客户端：同款白名单 Set.has() 运行时检查，非法名→过滤，未知动作→IDLE，完全乱码→hallucination_guard
```

### 27. 三级容错

1. DeepSeek API（2 次重试 + 退避）
2. 超时降级（45s）→ `mockInterpretPrompt()` 关键词路由
3. 网络错误降级 → 本地备用（含品质/WorldEvent/AfterShock/历史记忆）

### 28. 双部署模式

- 开发：Vite + `vite-plugin-divine-api.ts` 内联 Express（`localhost:5173`）
- 独立：`node server.js` 端口 3001
- **Vercel Serverless**：`api/index.js` 单入口处理全部 `/api/*` 路由
- `api/_shared.js` — 共享的 sanitizer + DeepSeek 调用逻辑
- `vercel.json` — SPA 路由重写 + 自动构建配置
- 环境变量 `DEEPSEEK_API_KEY` 在 Vercel Dashboard 设置，未设置时自动降级离线模式
- 在线演示：[prompt-genesis-eight.vercel.app](https://prompt-genesis-eight.vercel.app)
