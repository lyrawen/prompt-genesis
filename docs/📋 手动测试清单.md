# Prompt Genesis — 手动测试清单

> 按效果类型分组，验证本次改动是否达到预期效果。

---

## 一、核心玩法测试（NPC 路由 + 并行执行）

### 用例 1 — 全员调度（检验并行行走）

**输入：**

```
阿强去砍树，阿珍去读书，阿衰去睡觉
```

**预期效果：**

- [ ] 三人**同时**调头，拉出三条平行奔跑轨迹
- [ ] 阿强 → 古松森林（右上），动画挥斧 CHOP，头顶 `💪`
- [ ] 阿珍 → 岭南书斋（左下），面前浮白色矩形书卷，头顶 `🧠`
- [ ] 阿衰 → 竹榻营地（右下），躺平喷 `💤`，头顶 `😌`
- [ ] 状态栏：木材 +2，知识 +2，饱食度 -5 +8 = +3

---

### 用例 2 — 让 NPC 做不擅长的事（检验人格系统）

**输入：**

```
阿强去读书，阿珍去砍树，阿衰去砍树
```

**预期效果：**

- [ ] 阿强头顶 `😩`（力量型被迫读书）
- [ ] 阿珍头顶 `😩`（学者型被迫砍树）
- [ ] 阿衰头顶 `😅`（谁都不想干活）
- [ ] 资源增量应明显少于用例 1（SYSTEM_PROMPT 调整了效率倍率）

---

### 用例 3 — 恢复指令（检验饱食度机制）

**输入：**

```
阿衰去躺平休息
```

**预期效果：**

- [ ] 阿衰走向竹榻，横躺喷 `💤`
- [ ] 头顶 `😌`（恢复型做擅长的事）
- [ ] 饱食度上升（hungerDelta = +8）

## 二、叙事引擎测试（WorldEvent）

### 用例 4 — 触发环境事件

**输入：**

```
暴风雨要来了！阿强快去砍树，阿珍回书斋躲雨
```

**预期效果：**

- [ ] NPC 正常执行行动
- [ ] **世界事件通知条出现**（HUD 底部淡入），例如：
  - ⛈️ 狂风骤起！古松林落下几根断枝。
  - 或 🌧️ 天空飘起细雨，书页微微湿润，但万物生长。
- [ ] 镜头轻微闪烁/震动（STORM 触发 `camera.flash` + `camera.shake`）
- [ ] 资源变化包含事件额外影响

---

### 用例 5 — 另一种事件

**输入：**

```
今晚的月色真美，阿珍在月光下读书吧
```

**预期效果：**

- [ ] 月夜世界事件弹出（MOONLIGHT）
- [ ] 🌙 月光洒落，林间一片清明，信徒们精神为之一振。
- [ ] 镜头泛蓝光闪烁（`camera.flash` RGB 200,220,255）

---

### 用例 6 — 无事件触发

**输入：**

```
阿强去砍树
```

**预期效果：**

- [ ] 没有世界事件通知条
- [ ] 只有阿强的正常行动反馈

## 三、末日高潮测试（粒子 + 镜头）

### 用例 7 — 观察大洪水粒子

**操作：**

1. 点击 **开始求生**
2. 输入任意神谕
3. 盯着屏幕四周观察

**预期效果：**

| 阶段 | 效果 |
|------|------|
| ⏳ 倒计时 50s+ | 少量墨滴粒子缓慢飘落 |
| ⏳ 倒计时 30s- | 粒子变密、速度加快 |
| ⏳ 倒计时 10s 内 | **粒子密集喷射**，四周墨滴晕染 |
| 参数变化 | 频率 600ms→80ms，速度 12→40，粒子大小 0.5→1.2 |
| 最后 10 秒神谕 | **镜头剧烈震动** |

## 五、完整游戏流程测试

### 用例 11 — 生存压力 + 胜利结局

**输入（连续 2-3 次）：**

```
风暴要来了，强壮的赶紧去砍树，聪明的去读书，剩下的去睡觉恢复体力！
```

**验证项：**

- [ ] 饱食度每 5 秒自动 -2%，进度条从翠绿→橙黄→红色
- [ ] 木材/知识进度条在神谕后暴涨
- [ ] 倒计时到 0 时：若 wood≥3 且 knowledge≥3 → 弹出胜利弹窗
- [ ] 点击"再来一局" → 完全重置，世界事件通知条隐藏

## 六、一键快速验证（5 分钟通关）

| 顺序 | 输入 | 验证重点 |
|------|------|---------|
| 1 | 点击 **开始求生** | 倒计时启动，饱食度开始滑落 |
| 2 | `阿强去砍树，阿珍去读书，阿衰去睡觉` | 并行行走 + 心情 emoji + 资源变动 |
| 3 | `暴风雨要来了！阿强砍树，阿珍读书` | 世界事件通知 + 镜头反馈 |
| 4 | 等到倒计时 <10s，输入 `全员全力！` | 粒子密集度 + 镜头震动 + 结局 |
